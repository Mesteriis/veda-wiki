# Удаление перевода из VEDA

Дата: 2026-11-04. Решение владельца: «перевод выкинем совсем — удалить функцию из кода».

## Что удаляется

- Пакет `internal/translation` целиком: локальный воркер (Ollama, MLX, OpenAI-совместимый), разбиение на части, проверки, сохранение.
- Флаги CLI `--translation-local-url`, `--translation-model`, `--translation-token-file`, `--translation-protocol`, `--translation-interval`. На LXC161 они не используются (проверено по юниту systemd).
- REST: `/api/v1/articles/display`, `/api/v1/articles/display-excerpt`, `/api/v1/articles/translation`, `/api/v1/articles/translation-validate`, `/api/v1/articles/translation-needed`. Эти маршруты существуют только ради перевода: «отображаемый» текст без перевода совпадает с оригиналом.
- MCP-инструменты: `veda_read_display`, `veda_read_display_excerpt`, `veda_prepare_translation`, `veda_translation_needed`, `veda_translate_article`. Golden `internal/mcp/testdata/tools.json` обновляется.
- Домен: `Article.Translation`, `Move.TranslationFingerprint`, поля перевода в `Page` (`TranslationOrigin`, `TranslationState`, `OriginalSHA`, `Translated`), `DisplayedRevision` и всё, что переносит, копирует, импортирует или проверяет перевод.
- Интерфейс: метки перевода и хешей в статье, перевод в типах API, предупреждения источника, связанные с переводом.
- Документация: `docs/translation.md` удаляется, упоминания в остальных документах убираются; скрипты проверки перевода удаляются, остальные смоуки перестают сеять и проверять перевод.

## Решения исполнителя (мои)

- **Формат хранилища не меняется (v21).** Поля удаляются из структур Go; ключи `translation` и `translation_fingerprint` в уже записанных JSON-записях загрузчик игнорирует, и они исчезают при следующей записи статьи или переноса. Поэтому откат на `81dfeb2` остаётся возможным: старый бинарник открывает базу без переводов. Сохранённые на LXC161 переводы перестают показываться сразу и физически исчезают по мере перезаписи статей.
- **Тексты интерфейса, классы и роли** остальных экранов не меняются. Экран программной документации теряет метки перевода; эталонные скриншоты пересниматься только для экранов, где была метка, после просмотра различий.
- **Поиск** индексирует только оригинал.
- Никаких новых возможностей и попутных правок.

## Анти-цели

- Ломается чтение, поиск, перенос, копирование, импорт, синхронизация или MCP для статей без перевода.
- Остаются мёртвые ветки, флаги, маршруты или тексты про перевод.
- Ослабляются тесты, не связанные с переводом.
